# OUTPOST
An interactive mission simulator where players run a Moon or Mars outpost, make engineering decisions, and discover how those decisions determine whether the crew survives.

Imagine managing an outpost with four astronauts. You decide how to allocate power, how much radiation shielding to install, how efficiently to recycle water, and how to manage food and oxygen supplies.

But here's the interesting part: everything is interconnected.
- More food production requires more power and water.
- More radiation shielding protects the crew but increases the outpost's mass.
- Power shortages can affect life-support systems.
- Poor water recycling depletes reserves faster.
- One bad decision can trigger a chain reaction across multiple systems.
